# Code of Conduct

## Our Pledge

We pledge to make participation in GlucoVision a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender, religion, or level of experience. This is a health project for rural India — be kind, be respectful.

## Standards

- Use welcoming, inclusive language
- Be respectful of differing viewpoints
- Accept constructive criticism gracefully
- Focus on what is best for PHC users and patients

## Enforcement

Report unacceptable behavior to `manish-9245` via GitHub Issues (private) or email. All complaints will be reviewed and investigated.
